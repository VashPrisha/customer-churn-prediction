Built a machine learning model to predict customer churn using classification algorithms achieving 85% accuracy. Designed and deployed an interactive Streamlit dashboard for realtime churn prediction.

# Customer Churn Prediction

This project predicts customer churn using machine learning. Built using the Telco dataset from Kaggle.


## Features

- Full EDA, preprocessing and model training in Jupyter notebook
- Interactive Streamlit app for:
  - Single-customer prediction
  - Batch prediction via CSV
- Downloadable results


## ML models used

- Logistic regression
- Scikit-learn pipeline
- StandardScaler + LabelEncoding
